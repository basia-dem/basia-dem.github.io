01 / ABOUT

Find it before they do.

Hi, I'm Barbara — a Pentest Engineer and ISTQB-certified Software QA Engineer who genuinely enjoys finding the edge cases (and the security holes) everyone else overlooked.

As owner and managing director of Helvetia Pixel, I lead a digital agency in Lenzburg that helps Swiss SMEs modernise safely. My focus there is authorised security assessments — web apps, APIs and Azure cloud infrastructure, always with a written scope, a severity-rated report and an optional retest.

Before that I spent years in software QA: structured test design across all test levels, manual & exploratory testing, REST API testing with Postman, and traceable test cases in Jira & Xray. I was the Software QA Engineer for the iOS apps Alps Summits and Abfahrtli, both live on the App Store.
